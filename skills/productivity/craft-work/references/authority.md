# Authority

| Work | Canonical system |
| --- | --- |
| Plans, goals, projects, specifications, decisions, people, meetings, tasks, bookmarks, readable runbooks | Craft |
| Development assignment, locks, execution, retries, QA, approvals | Paperclip |
| Shared source-scoped knowledge and provenance-aware discovery | GBrain |
| Private agent/Elliott continuity | Profile/local memory |
| Historical evidence | Obsidian, Todoist, Microsoft To Do |

Craft owns readable reference/work records and outcomes. Paperclip owns the
development execution lifecycle. GBrain stores cited source-scoped knowledge
for retrieval and does not replace Craft or private memory. Link overlapping
records by stable IDs and canonical URLs, never title alone.

When current Craft conflicts with legacy evidence, Craft is current authority;
preserve and surface the historical conflict rather than overwriting either.
